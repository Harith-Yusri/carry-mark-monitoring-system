CAMS bundles English (`en`), Bahasa Melayu (`ms`), Simplified Chinese (`zh`), and Tamil (`ta`) dictionaries. The Staff Portal imports this same resource engine, so terminology stays consistent across platforms. English UI phrases are keys; key and namespace separators are disabled because phrases may contain punctuation. Keep all four JSON key sets and interpolation placeholders identical.

Use `t()` for CAMS-owned labels and sentences. Insert names and academic content as interpolation values, never as translation keys. Never pass database names, descriptions, lecturer responses, or correction reasons through `t()` or `tx()`. Assessment-type selector labels may be translated; their submitted enum values and previously stored type/name text stay unchanged.

Use `tx()` only where a controlled error/status/notice is displayed. It recognizes bundled messages and approved backend validation categories while retaining English fallback for unknown messages. `notificationText(text, subjects)` matches complete bundled CAMS notification templates against known subjects/assessments without modifying the subject, lecturer or assessment values inside them; unrecognized notification text remains unchanged. CSV output and externally delivered push/email bodies retain their existing formats.

The platform adapters subscribe to the locale store with `useSyncExternalStore`. Components call `useLocale()` to rerender. The translator references stay stable: do not add locale to data-fetch dependencies or use it as a component/provider key. `auto` uses browser preference tags or the device's standard Intl default locale, matching language subtags to the nearest supported locale, then English. Preferences use `cams.language.v1` in web localStorage or native SecureStore. Neither adapter reads/writes academic records or auth credentials.

Run `node --test tests/localization*.test.mjs` and `node scripts/audit-localization.cjs` from the repository root. The audit catches literal JSX text and user-facing attributes; review expression/helper/template boundaries as well. Brand names, database content and CSV acronyms are intentionally excluded from translation. Native OS/browser permission and built-in validation dialogs follow the operating system/browser language.
