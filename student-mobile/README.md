# CarryMark Student Android App

The Kotlin and Jetpack Compose student app for the UiTM Carry Mark Monitoring System. It shares the Supabase backend used by the lecturer and administrator web portal.

## Run it

1. Open Android Studio.
2. Choose **Open** and select this `student-mobile` folder.
3. Let Gradle sync and install Android SDK 35 if prompted.
4. Run the `app` configuration on an emulator or Android device (Android 7.0+).

Student login:

- Enter the student's matrix number.
- The app converts it to the matching UiTM Auth email, such as `20221123003@student.uitm.edu.my`.
- Accounts and password resets are managed by the administrator.

## Included student flow

- Student login
- Semester dashboard
- Carry mark and eligibility status per subject
- Assessment-by-assessment breakdown
- Join a lecturer's class using its generated class code
- Submit a mark issue/dispute to Supabase

## Supabase configuration

Create `local.properties` in this folder and keep the Android SDK line generated by Android Studio. Add:

```text
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_PUBLISHABLE_KEY=your-publishable-key
```

`local.properties` is ignored by Git. Never put a Supabase service-role key in the Android app. Carry-mark calculations and access checks run in PostgreSQL, while the app only receives records belonging to the authenticated student.
